    חיבור לגוגל שיט

    הדביקו את כתובת ה-Web App מ-Apps Script. אחרי שהחיבור עובד, שימו אותה בקבוע API_URL בראש הקובץ כדי שכל המשפחה תתחבר אוטומטית.

    1. בגיליון המשותף: Extensions → Apps Script
    2. הדביקו את הקוד מ-google-apps-script.gs
    3. Deploy → New deployment → Web app
    4. Execute as: Me · Who has access: Anyone
    5. העתיקו לכאן את כתובת ה-/exec
